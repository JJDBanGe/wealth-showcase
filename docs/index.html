判断标准（现金视角）：
① 模拟期内现金最低点 ≥ 应急金 = ✅ 不用卖股票（花完仍在安全垫之上）
② 现金最低点在 0 与应急金之间 = ⚠️ 会动到应急金（花完低于 6 个月必要支出）
③ 现金最低点 < 0 = ❌ 现金不够，要么分期、要么卖股票
三种间隔的区别（现在真的不一样了）：「同一月内 × N 次」= 一次性拿出 N×单次； 「每月一次 × N」= 分摊到 N 个月，期间每个月还有你的月结余 12,803 HKD补进来， 所以只要单次 ≤ 月结余就不会动到应急金；「每年一次 × N」= 每 12 个月一次，中间累积的结余更多，压力最小。 判断口径统一为「模拟期内的现金最低点」和应急金比较。
判定对象是「累计金额」（单次金额 × 次数），不是单次——否则"每次 5,000、每月一次"这类重复消费每次都会被判成无影响；同时会列出"本月已发生的大额消费"（单笔 ≥ 单笔冷静期额度，从流水自动筛选），避免已经花掉的那几次被忽略。
口径：支出只从现金/短债出、不卖股票，所以主判断用「可花现金 = 演示现金 − 应急金」；「卖股票」那一栏只在③的情况下才需要看，它用的是原来的口径（按选定年化逐月模拟 FIRE 推迟）。
