# 发布这个独立展示版

## 本地审阅

1. 用 VSCode 打开本展示版目录，检查 README、主报告、工作台和时间线。
2. 运行 `python -m pytest tests/ -v` 和 `python scripts/gen_report.py`。
3. 检查待提交文件。应包含合成 HTML 和截图；不得加入个人数据、环境文件、账户导出或原仓库的 `.git`。

## GitHub 发布

本展示版使用独立公开仓库：<https://github.com/JJDBanGe/wealth-showcase>。原私有项目的可见性与历史保持独立。

首次发布说明：`feat: publish offline wealth showcase with synthetic data`。提交正文说明四页报告、原框架只读工作台、数据范围、源提交元数据及验证结果。公开仓库从这次发布开始积累自己的历史。

不要设置原私有项目的地址作为这里的远程仓库。公开版仅提交已审阅的展示文件，不包含旧仓库的完整历史或凭据。后续提交前继续检查原始数据、环境配置和截图。

## 对外介绍历史

可以准确说明：

> 这个展示版来自我持续迭代的个人财务项目。源项目截至导出时有 133 条可达提交，展示版附有从真实 Git 元数据提取的脱敏时间线。为保护个人数据，公开仓库从展示版开始积累独立历史；时间线不包含私有提交的完整差异。

原始作者日期和短哈希在 `development-history.json` 中，提交正文、邮箱和私人路径已省略。不要把 133 条源提交说成新公开仓库的提交数量，也不要为了增加数量制造提交或倒填日期。

## 演示维护

修改代码后重新生成 HTML 和截图，执行检查，再一起提交。不要用日常账本生成的 HTML 覆盖这里的文件。`demo/fixtures.py` 是唯一演示输入入口。

本次保留了源项目的专有使用权定位。公开可见与授予开源许可证是两回事；需要开放复制或商业使用时，再由所有者选择许可证。
