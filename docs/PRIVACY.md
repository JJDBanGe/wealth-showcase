# 数据与脱敏范围

本展示版的财务、消费与交易数据全部为合成输入。它们由固定种子或明确的示例常量构造，没有对真实交易逐笔改名、缩放金额或挪动日期。

| 内容 | 来源与处理 |
| --- | --- |
| 消费交易、姓名/商户描述 | `demo/fixtures.py` 从固定种子生成，描述使用 DEMO / SYNTHETIC 标识 |
| 工资、房租、定投、资产与现金 | 展示版示例常量，不读取个人账本和本机配置 |
| 期权候选、报价、持仓与订单 | `demo/workspace.py` 重新构造；标的、合约标识与订单编号为 DEMO 示例 |
| 工作台检查、日历与审计 | 固定合成结果；事件日仅用于展示，不是已核验的经济发布日历 |
| 收益曲线 | 合成日收益计算，不是作者业绩 |
| 页面截图 | 由上述合成页面生成；未截图个人账户或真实服务 |
| 提交数量、作者日期与短哈希 | 保留真实源项目元数据，用于说明开发过程；未导出姓名、邮箱、原始提交正文、私人文件路径或完整差异 |
| 功能演进描述 | 根据六条真实源提交整理，不包含个人运行记录和金融授权历史 |
| 计算与界面代码 | 复用通用实现；原个人配置、设备标识、授权规则文档和后台账本未复制 |

生成器不读取 `.env`、个人数据目录、数据库或券商导出；不导入券商后台，不连接本机服务、注册启动入口或发送下单请求。交易/维护按钮在公开版被禁用，日历与详情等浏览交互保留。

本次检查覆盖公开目录内的源文件、HTML、文档、元数据和已生成截图的来源；文本与已知姓名、特定交易标识、设备指纹、个人财务参数以及本机账户/密钥值进行匹配，未发现残留，也未携带原始财务文件。工作台新增模板和合成快照已纳入复查。

真实开发元数据是有意保留的信息，因此不应把本项目描述为“所有内容都虚构”或“完全匿名”。上述检查说明已核查的范围，不构成对所有未知敏感信息的绝对保证。未来修改数据或重新截图后，需要重新审阅。
